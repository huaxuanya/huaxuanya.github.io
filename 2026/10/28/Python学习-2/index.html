注释

注释是写给人看的,Python 运行时会直接跳过
单行注释用 #,多行注释用三个引号包起来

上面这段跑起来只会打印两行
注释最实用的地方不是”解释代码”,而是临时把一段代码关掉,调试的时候比删掉再写回来省事

数据类型

Python 不用提前声明类型,赋值的时候它自己会记
用 type() 就能看到一个变量到底是什么类型

输出里那个 181 不是一百八十一,而是把 “18” 和 “1” 两个字符串接在了一起
这就是类型的区别:同样是 +,数字做加法,字符串做拼接
整数和字符串直接相加会报 TypeError,所以才需要 str() 这类转换函数

input:让程序问你一句话

input() 的作用是把键盘输入的内容读进来
它读到的永远是字符串,想当数字用就得转换

括号里那句话是提示语,会直接显示在光标前面
因为它读回来的是字符串,所以算完还得再转回字符串,一来一回有点啰嗦
后面学了格式化字符串,这些 str() 就都可以省掉
