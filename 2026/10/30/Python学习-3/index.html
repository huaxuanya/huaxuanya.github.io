条件语句:让程序自己做选择

这期的核心只有一件事:如果……就……
对应视频教程里”对象今天会生气吗”那一节

if 和 else

基本写法是 if 条件: 换行缩进写要做的事
条件成立就走 if 下面的缩进块,不成立就走 else

有三点要注意:第一,冒号不能少;第二,缩进四个空格,缩进决定这几行属于谁;第三,判断相等要用 == 两个等号,一个等号是赋值
常用的比较符号是 == != > < >= <=
运行效果↓

elif:一个条件不够用

elif 就是 else if,条件可以一条一条往下排
只要前面有一条成立,后面的就不会再看了

顺序是有讲究的,如果先写 分数 >= 60,那 85 分也会被判成”及格”
所以多条件判断要从严格到宽松往下排
运行效果↓

逻辑运算:and、or、not

and 两边都成立才行,or 一边成立就行,not 取反
用它们可以把几个小条件拼成一个大条件

嵌套判断(在 if 里面再写 if)也常用,但层数一多就读不懂了,能用 and 拼起来就尽量拼

结语

判断语句本身的语法不难,难的是把所有情况想全,漏掉一个分支程序就会走进 else
