循环:把重复的事交给电脑

电脑最擅长的就是重复,而写重复代码恰恰是人最不擅长的
这期就两个循环:for 和 while

for 循环:数量确定的时候用

for … in … 的意思是:把这个东西里的每一项挨个拿出来
range(起点, 终点) 生成一串数字,取头不取尾

range(1, 4) 只给出三个数,所以跳了三次绳
第二个例子是把列表里的每一项依次拿出来判断,和上期的 if 拼在一起用

while 循环:条件成立就一直转

while 条件: 只要条件成立,就一直执行下面的代码
所以循环体里一定要有改变条件的语句,否则就是死循环

要是漏掉 圈数 = 圈数 + 1,程序会不停打印”第1圈”,这时在终端里按 Ctrl+C 就能强行停掉
跑飞了别慌,学循环的人基本都要经历一次

格式化字符串:拼字符串的优雅解法

前面为了把变量塞进字符串,写了一堆 str() 和 +
f-string 只要在引号前加个 f,花括号里就能直接写变量

花括号里甚至可以写算式,比如 f"{1 + 1}"
上期那句 "明年你就" + str(年龄 + 1) + "岁了",现在写成 f"明年你就{年龄 + 1}岁了" 就行
