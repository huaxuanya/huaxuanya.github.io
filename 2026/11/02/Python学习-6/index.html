函数和模块

写多了会发现,总有几段代码被复制来复制去
这期把它们打包起来:函数,以及直接拿来就用的模块

def:给自己造一个命令

用 def 名字(参数): 定义函数,之后写一次名字就能调用
return 把算出来的结果交回给调用它的地方

参数是函数运行时才填进去的值,像 算BMI(1.75, 70) 里的身高和体重
return 和 print 很容易混:print 是给人看的,return 是给程序用的
所以 结果 = 算BMI(...) 能拿到返回值;如果函数里只 print 不 return,结果 会是 None

import:别人写好的,拿来吧你

Python 自带了一大批标准库,import 一下就能用
只想要某个函数的话,也可以 from 模块 import 函数

math 就是上次算一元二次方程时用到的那个模块,它的函数在官方文档里都有
random 每次运行结果都不一样,所以才适合用来决定”今天吃什么”
自己写的函数也能单独存成 my_tools.py,放在同一个文件夹里,import my_tools 就能用
